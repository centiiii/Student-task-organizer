About Student Task Organizer

About this project

Student Task Organizer is a simple web app that helps college students keep track of schoolwork in one place, instead of scattered across chat messages, notes, and memory.

What you can do

  • Add tasks with a title, subject, due date, and priority
  • Mark tasks as done, edit them, or delete them
  • See tasks sorted by due date, with overdue and due-today tasks clearly marked
  • Filter the list by subject
  • Keep your tasks saved between visits

How it works

The site is built with plain HTML, CSS, and JavaScript, with no frameworks or accounts. Your tasks are saved in your own browser and are never sent anywhere. See the Privacy Policy for details.

About the build

Known limitations

Tasks live only in one browser on one device, so clearing browser data or switching devices means starting over. A backup feature is planned.
